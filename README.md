# My Favorite Series: Attack on Titan

**Attack on Titan** is an action-packed anime about humanity fighting to survive against giant creatures called *Titans* behind massive walls.

## Main Characters
* **Eren Yeager**
* **Mikasa Ackerman**
* **Armin Arlert**
* **Levi Ackerman**

### Why I Would Recommend It
1. Unpredictable plot twists that keep you hooked
2. Deep and complex character development
3. Top-tier animation and epic soundtrack
